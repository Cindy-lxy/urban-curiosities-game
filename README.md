# 都市奇闻：鬼怪还是谣言？

中英双语互动网页游戏。玩家将在城市怪谈、校园传闻与职场异闻中调查线索，判断眼前事件究竟是鬼怪作祟，还是人为制造的谣言。

## 在线运行

本项目为纯静态网页，可直接部署到 GitHub Pages。打开 `index.html` 即可运行，游戏进度与语言偏好保存在浏览器本地。

## 主要内容

- 中英双语切换
- 21 个剧情章节、调查热点、论坛内容与多结局
- 剧情回看、章节选择和本地存档
- PC、平板、手机竖屏与横屏适配
- 18 张 WebP 场景及线索图片，兼顾清晰度和加载速度

## 文件结构

- `index.html`：页面入口
- `style.css`：界面与响应式样式
- `story.js`：中文剧情和游戏数据
- `en_story.js`：英文显示词典
- `i18n.js`：语言切换
- `game.js`：游戏逻辑、交互与存档
- `assets/`：WebP 场景及线索图片
